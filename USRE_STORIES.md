## Пользовательские истории (User Stories)

1. **Просмотр посещаемости**
   * **Как** пользователь (преподаватель или староста)
   * **я хочу** видеть общий список посещаемости группы 2ИП-5 в виде удобной таблицы
   * **чтобы** сразу понимать, кто присутствует на занятиях, а кто отсутствует

2. **Добавление записи**
   * **Как** пользователь
   * **я хочу** добавлять новую запись о посещении студента (с указанием ФИО, группы, предмета, даты и статуса)
   * **чтобы** фиксировать текущие данные в системе

3. **Поиск записей**
   * **Как** пользователь
   * **я хочу** искать информацию по фамилии, группе или предмету
   * **чтобы** быстро находить нужного студента среди всех записей

4. **Редактирование**
   * **Как** пользователь
   * **я хочу** изменять данные в существующих записях по их ID (например, сменить статус с отсутствует на опоздал)
   * **чтобы** вовремя исправлять неточности

5. **Удаление**
   * **Как** пользователь,
   * **я хочу** удалять ненужные или ошибочные записи по ID
   * **чтобы** в базе данных не накапливался мусор
