# Система учета посещаемости 

Rонсольный проект на тему система учета посещаеомти на python

## Что тут есть (стек):
* **Python** (основа всего)
* **JSON** (чтобы данные не стирались при закрытии проги)
* **Pytest** (проверяем, что код реально работает)

## Структура файлов:
* `main.py` — само консольное меню, через которое всё запускается
* `attendance.py` — вся логика (добавление, поиск, удаление студентов)
* `data/attendance.json` — тут хранятся записи
* `tests/test_attendance.py` — тесты

## Как запустить:

1. Сначала подтягиваем виртуальное окружение:
   * На Windows:
     ```bash
     python -m venv venv
     venv\Scripts\activate
     ```
   * На Linux / macOS:
     ```bash
     python -m venv venv
     source venv/bin/activate
     ```

2. Прогоняем тесты (проверяем работоспособность):
     ```bash
     python -m pytest
     ```

3. Запускаем саму прогу:
     ```bash
     python main.py
     ```
